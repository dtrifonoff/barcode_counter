# Баркод Инвентар

Flutter приложение за сканиране на баркодове и управление на инвентар.

## Функционалност

- ✅ Сканиране на баркодове с камера
- ✅ Въвеждане на количество (клавиатура + +/- бутони)
- ✅ Запазване на сесии с множество артикули
- ✅ История на всички сесии
- ✅ Редактиране на количества
- ✅ Изтриване на артикули
- ✅ Експорт в Excel (.xlsx)
- ✅ Копиране в клипборда (формат: баркод;количество)
- ✅ Запазване на сесии при рестарт на приложението

## Изисквания

- Flutter SDK 3.38.5 или по-нова версия
- Android SDK (minSdkVersion 21)
- Android устройство или емулатор с камера

## Инсталация

1. Клонирайте проекта или отворете папката
2. Инсталирайте зависимости:
   ```bash
   flutter pub get
   ```

3. Стартирайте приложението:
   ```bash
   flutter run
   ```

## Използване

### 1. Нова Заявка
- Натиснете бутона **"Нова Заявка"** на началния екран
- Дайте разрешение за достъп до камерата (само при първо стартиране)
- Насочете камерата към баркод
- Въведете количество (чрез клавиатура или +/- бутони)
- Натиснете **"Добави"** за да запазите артикула
- Повторете за всички артикули
- Натиснете иконката **✓** в горния десен ъгъл за да завършите заявката

### 2. Продължи Текуща
- Ако имате незавършена сесия, този бутон ще се покаже на началния екран
- Натиснете за да продължите сканирането

### 3. История
- Преглед на всички завършени сесии
- Натиснете сесия за да видите детайли
- Плъзнете наляво за да изтриете сесия

### 4. Детайли на Сесия
- Преглед на всички артикули в сесията
- Натиснете иконката **✏️** за да редактирате количество
- Натиснете иконката **🗑️** за да изтриете артикул
- Натиснете **"Експорт Excel"** за да създадете .xlsx файл
- Натиснете **"Копирай"** за да копирате данните в клипборда

## Формат на Експорт

### Excel (.xlsx)
```
Баркод      | Количество
--------------------------
1234567890  | 5
9876543210  | 3
```

### Клипборд (текст)
```
1234567890;5
9876543210;3
```

## Технологии

- **Flutter** - UI framework
- **mobile_scanner** - Сканиране на баркодове
- **sqflite** - Локална SQLite база данни
- **provider** - State management
- **excel** - Генериране на Excel файлове
- **share_plus** - Споделяне на файлове
- **permission_handler** - Управление на разрешения
